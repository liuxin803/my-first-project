# 小舟导航

这是一个使用原生 HTML、CSS 和 JavaScript 构建的中文个人导航网站，用来集中收藏常用的工具、资源和生活网站。不需要安装依赖或构建工具。

## 快速开始

直接在浏览器中打开 `index.html` 即可使用导航网站。

也可以在项目目录运行一个本地静态服务器：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 功能

- 按网站名称、描述或分类搜索
- 开发工具、设计资源、学习成长、娱乐生活四类常用网站
- 支持浅色和深色模式，并使用浏览器本地存储记住选择
- 响应式布局，适配手机和桌面屏幕
- 网站链接在新标签页打开

## 项目结构

- `index.html`：导航网站首页，包含页面结构、样式、网站数据和交互逻辑
- `README.md`：项目说明和使用方式
- `.gitignore`：Git 忽略规则

## 自定义网站

打开 `index.html`，在脚本中的 `links` 数组里新增或修改网站信息即可。每条网站数据包含网站名称、描述和网址。
