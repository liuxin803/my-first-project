# 我的第一个独立项目

这是一个从零开始制作的中文项目首页，使用原生 HTML、CSS 和 JavaScript 构建，不需要安装依赖或构建工具。

## 快速开始

直接在浏览器中打开 `index.html` 即可预览首页。

也可以在项目目录运行一个本地静态服务器：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 项目结构

- `index.html`：项目首页，包含页面结构、样式和按钮交互
- `README.md`：项目说明
- `.gitignore`：Git 忽略规则
